Simulador comercial — captura mes a mes
Captura en cada mes las licencias Web vendidas, las Desktop anuales y las cancelaciones Web (doctores que dejan de pagar después de 1–10 meses, por ejemplo). El simulador recalcula la base activa acumulada, el ingreso recurrente, el tramo de comisión sobre ventas nuevas, el bono trimestral sobre activos retenidos y tu utilidad neta. Nada de esto se guarda ni afecta datos reales.
